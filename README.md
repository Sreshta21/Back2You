# Back2You

**Back2You** is a community-based web application designed to help users recover lost items efficiently. It allows individuals to post about lost or found items and enables claim verification through a secure quiz mechanism.

---

## Features

-  Post lost or found items with details and images
-  Claim verification via quiz to ensure rightful ownership
-  Track 15-day item history for claims and returns
-  Smart UI with modal forms and dynamic item displays
-  Firebase Firestore integration for real-time data storage

---

## Tech Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Firebase Firestore (NoSQL Database)
- **Authentication:** Firebase Auth (planned)
- **Tools:** VS Code, GitHub, Firebase Console

---

## How It Works

1. Users add a **Lost** or **Found** item with details like name, location, color, and optional image.
2. Found items can be **claimed** through a quiz that matches the original submission.
3. If all answers match, contact information is shared with the claimant.
4. Items can also be marked as **Returned** and stored in the 15-day **History** section.
